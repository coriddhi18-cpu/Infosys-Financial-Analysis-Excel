# Infosys Financial Analysis – Excel

## 📊 Project Overview

This project analyzes the financial performance of Infosys using data from its Integrated Annual Report 2025–26.

The analysis covers FY2024, FY2025 and FY2026 and was completed using Microsoft Excel.

## 🎯 Objectives

- Analyze revenue and net profit growth
- Evaluate profitability
- Analyze liquidity
- Measure return on equity and assets
- Evaluate asset efficiency
- Analyze cash position
- Identify key financial trends

## 📈 Financial Metrics Analyzed

- Revenue Growth %
- Net Profit Growth %
- Net Profit Margin
- Current Ratio
- Return on Equity (ROE)
- Debt-to-Equity Ratio
- Asset Turnover Ratio
- Cash Ratio
- Return on Assets (ROA)
- PBT Margin
- Dividend Payout %

## 🛠️ Tools Used

- Microsoft Excel
- Excel formulas
- Financial ratio analysis
- Charts
- PivotTable
- Trend analysis

## 📅 Period Covered

| Year | Revenue (₹ crore) | Net Profit (₹ crore) |
|------|-------------------:|---------------------:|
| FY2024 | 153,670 | 26,233 |
| FY2025 | 162,990 | 26,713 |
| FY2026 | 178,650 | 29,440 |

## 🔍 Key Findings

- Revenue increased by approximately 10% in FY2026.
- Net profit increased by approximately 10% in FY2026.
- Net profit margin remained around 16%.
- ROE increased from approximately 28% to 32%.
- Asset turnover improved from 1.09 to 1.15.
- Current ratio decreased from 2.27 to 1.98 but remained above 1.
- Cash ratio decreased from 0.57 to 0.42.
- ROA improved from approximately 18% to 19%.
